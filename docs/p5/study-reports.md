# User 1
My first user was a senior 6-4 MIT student who is not in 6.1040.

## Task 1
Upon first inspection, this user was immediately familiar with the interface of clicking and dragging around the map. The first major hurdle I noticed was that he struggled to connect places on the map with buildings that he was familiar with. Without photo overlays or pop-ups as seen in other mapping apps, he clicked around slowly trying to find a particular building at MIT.

## Task 2
The user was immediately able to find the sign-up page and fill in his account details, likely because Sticky follows design standards set by other web apps. 

He revealed a technical bug in the design that only occurs when a user attempts a Commons log-in, then cancels and attempts a regular login. This situation never occurred in my personal testing because Commons automatically signed me in when I clicked the log-in button.

## Task 3
The user was able to flawlessly create new notes. I believe that the pre-populated map with note dots made it easy for him to intuit that clicking on the map would allow him to write his own notes.

## Task 4
The user had no issues finding the edit/delete actions. 

An unexpected finding was that the dots on the map were too small to click comfortably. He had trouble clicking on his notes to open them and kept accidentally creating new ones instead. 

## Task 5
Same results as task 4: minor frustrations when clicking on notes.
